# Closed backlog rows — the archive

Rows that shipped or were answered, lifted out of [the queue](backlog.md) on
2026-09-06 so the queue holds only what is open. **Nothing here is a task.**

Each row keeps the closure note it was closed with. That note is why this file
exists rather than a `git log`: [CHANGELOG.md](../CHANGELOG.md) records what
changed, [build-status.md](build-status.md) what was built and each design its
own reasoning — none of them carries the sentence that says why the obstacle a
row named turned out not to be the obstacle. Several of these rows closed by
having their premise overturned, and that is the half a reader needs before
re-deriving the same wrong theory.

Order is the order the rows sat in, so a row cited from a design or a commit
is where its neighbours were.
