# Layouts Implementation Plan — `fit-blur` + `insert`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an episode place a framed rectangle of source footage anywhere in the canvas and fill the remainder, instead of always cropping the source to fill the canvas edge to edge.

**Architecture:** A layout is three parameters — a crop aspect + scale, a rect inside the canvas, and a background filler. `fill`/`fit-blur`/`insert` are presets over those three, not three code paths. Tracking is a consequence of geometry (`freedom = src_w - crop_w`), not a property of the layout. Everything downstream that needs to know what was actually cropped reads a new `path.meta.json` sidecar instead of re-deriving it.

**Tech Stack:** Python 3.13 in `.venv`, ffmpeg/ffprobe, pytest, dataclasses.

**Design spec:** [docs/specs/2026-07-10-layouts-design.md](../specs/2026-07-10-layouts-design.md)

```python
def even(n: float) -> int:
    """Round, then floor to an even int. Odd dimensions + yuv420p make libx264
    fail with 'width not divisible by 2' (spec §12) — and floor-truncated crop
    widths are odd half the time. Rounding first is load-bearing:
    even(2275.6) is 2276, not 2274."""
    i = int(round(n))
    return i - (i % 2)


def crop_for(aspect: tuple[int, int], scale: float, src_w: int, src_h: int) -> tuple[int, int]:
    """Largest crop of `aspect` that fits the source, times `scale`.

    NOT forced even: ffmpeg's crop filter takes odd sizes, and `fill` genuinely
    cuts 405px wide today. Evenness constrains what is scaled and encoded, and
    is applied at the output.
    """
    aw, ah = aspect
    if aw <= 0 or ah <= 0:
        raise ValueError(f"crop aspect must be positive, got {aspect!r} — "
                         "pass 'canvas', 'source', or a (w, h) pair of positive ints")
    if not 0.0 < scale <= 1.0:
        raise ValueError(f"crop_scale must be in (0.0, 1.0], got {scale!r} — "
                         "1.0 is the largest crop of this aspect that fits the source")
    if src_w <= 0 or src_h <= 0:
        raise ValueError(f"crop source must be positive, got ({src_w}, {src_h}) — "
                         "a corrupt probe or a caller bug upstream")
    if aw / ah <= src_w / src_h:
        h = src_h
        w = int(src_h * aw / ah)
    else:
        w = src_w
        h = int(src_w * ah / aw)
    return (int(w * scale), int(h * scale))


def freedom(crop_w: int, src_w: int) -> int:
    """Horizontal room the crop can travel in. Zero ⇒ nobody controls composition."""
    if crop_w > src_w:
        raise ValueError(f"crop {crop_w}px is wider than the source {src_w}px — "
                         "crop_for() clamps to the source, so this is a caller bug")
    return src_w - crop_w
```

Then replace the body of `crop_size`:

```python
def crop_size(canvas_w: float, canvas_h: float, src_w: int, src_h: int) -> tuple[int, int]:
    """Largest crop of canvas aspect that fits inside the source (fill mode)."""
    return crop_for((int(canvas_w), int(canvas_h)), 1.0, src_w, src_h)
```

Native canvas size is a float (`1280 * 16/9 = 2275.6`). Evening it *before* handing it to `Delivery` would drift: `even(405) * 16/9` is 718, not 720.

**This task is a pure, behaviour-preserving refactor — there is no red step.** `_even` has computed `int(round(n))` then `n - n % 2` since its first commit, making it byte-identical to the `geometry.even` Task 0 added, and `dims` already guards a nonpositive crop (added in `b044c93`, pinned by `test_delivery_dims_rejects_nonpositive_crop`). Floats already flowed through `dims` correctly; the `int` in its signature was a lie no type checker ever caught. What changes: one definition of `even` instead of two, and a signature that tells the truth. The new test is a regression pin on the float path, not a red-to-green step.

```python
    def dims(self, crop_w: float, crop_h: float) -> tuple[int, int]:
        """Even (out_w, out_h) for a composite of size (crop_w, crop_h).

        Takes floats: the native canvas height is `canvas_w * ah / aw` and
        evening either side before the other is derived would drift it.
        """
        if crop_w <= 0 or crop_h <= 0:
            raise ValueError(f"Delivery.dims needs a positive crop, got ({crop_w}, {crop_h})")
        if self.mode == "native":
            return even(crop_w), even(crop_h)
        if self.mode == "exact":
            return int(self.value[0]), int(self.value[1])
        ar = crop_w / crop_h
        if self.mode == "short_edge":
            if crop_w <= crop_h:
                w, h = self.value, self.value / ar
            else:
                h, w = self.value, self.value * ar
        else:  # long_edge
            if crop_w >= crop_h:
                w, h = self.value, self.value / ar
            else:
                h, w = self.value, self.value * ar
        return even(w), even(h)
```

Check for a circular import: `geometry.py` imports only `typing`, so `models → geometry` is safe.

```python
LAYOUT_MODES = ("fill", "fit-blur", "insert")
BACKGROUNDS = ("blur",)


@dataclass
class LayoutSpec:
    """Where the source lands in the canvas (spec §7). Three parameters, not
    three code paths: what to cut (aspect + scale), where to put it (rect), and
    what fills the rest (background).

    `rect` is (x, y, w) in canvas fractions — its HEIGHT is derived from the crop
    aspect, so a rect cannot disagree with what is placed inside it. None means
    full width, vertically centred.

    `fill` constrains crop_aspect and rect but deliberately not crop_scale: a
    scaled-down fill still fills the canvas, trading resolution for the
    horizontal freedom the tracker needs — the same trade fit-blur makes.
    """
    mode: str
    crop_aspect: str | tuple[int, int] = "canvas"
    crop_scale: float = 1.0
    rect: tuple[float, float, float] | None = None
    background: str = "blur"

    def __post_init__(self) -> None:
        if self.mode not in LAYOUT_MODES:
            raise ValueError(f"LayoutSpec.mode {self.mode!r} unknown — fill/fit-blur/insert "
                             "(split and pan are separate plans)")
        if self.background not in BACKGROUNDS:
            raise ValueError(f"LayoutSpec.background {self.background!r} unknown — "
                             f"{BACKGROUNDS}; solid lands with fit-solid")
        if not isinstance(self.crop_scale, (int, float)) or not 0.0 < self.crop_scale <= 1.0:
            raise ValueError(f"LayoutSpec.crop_scale must be in (0.0, 1.0], got "
                             f"{self.crop_scale!r} — 1.0 is the largest crop that fits")
        if isinstance(self.crop_aspect, str):
            if self.crop_aspect not in ("canvas", "source"):
                raise ValueError(f"LayoutSpec.crop_aspect {self.crop_aspect!r} unknown — "
                                 "'canvas', 'source', or a (w, h) pair of positive ints")
        elif not (isinstance(self.crop_aspect, tuple) and len(self.crop_aspect) == 2
                  and all(isinstance(v, int) and v > 0 for v in self.crop_aspect)):
            raise ValueError(f"LayoutSpec.crop_aspect {self.crop_aspect!r} invalid — "
                             "'canvas', 'source', or a (w, h) pair of positive ints")
        if self.rect is not None:
            if not (isinstance(self.rect, tuple) and len(self.rect) == 3
                    and all(isinstance(v, (int, float)) for v in self.rect)):
                raise ValueError(f"LayoutSpec.rect must be (x, y, w) canvas fractions or None, "
                                 f"got {self.rect!r} — height derives from the crop aspect")
            x, y, w = self.rect
            if not (0.0 <= x <= 1.0 and 0.0 <= y <= 1.0 and 0.0 < w <= 1.0):
                raise ValueError(f"LayoutSpec.rect {self.rect!r}: x/y must be fractions in "
                                 "[0, 1] and w must be in (0, 1]")
            if x + w > 1.0:
                raise ValueError(f"LayoutSpec.rect {self.rect!r}: x + w = {x + w:.3f} > 1.0 — "
                                 "the rect runs off the right edge of the canvas")
        if self.mode == "fill":
            if self.crop_aspect != "canvas":
                raise ValueError("LayoutSpec: fill must use crop_aspect 'canvas' — a fill that "
                                 "crops to another aspect needs a background, i.e. it is fit-blur")
            if self.rect not in (None, (0.0, 0.0, 1.0)):
                raise ValueError(f"LayoutSpec: fill covers the whole canvas, but rect is "
                                 f"{self.rect!r} — a fill with a smaller rect is an insert, "
                                 "and must say so")
        if self.mode == "fit-blur" and self.rect is not None:
            raise ValueError(f"LayoutSpec: fit-blur spans the full canvas width, so rect must "
                             f"be None, got {self.rect!r} — use insert to place a smaller rect")
        if self.mode == "insert" and self.rect is None:
            raise ValueError("LayoutSpec: insert needs a rect (x, y, w) in canvas fractions — "
                             "without one it is fit-blur")
```

`background` is deliberately not validated against `mode == "fill"`: a fill has nothing left to fill, so the field is simply ignored.

```python
@dataclass
class PathMeta:
    """What reframe ACTUALLY cut and where it put it — written beside path.json,
    exactly as track.py writes route.meta.json beside route.json.

    check_episode and storyboard read this instead of re-deriving the crop from
    the canvas. Under a non-fill layout the re-derivation is silently wrong: it
    returns the canvas-aspect crop width, divides by it, and reports a verdict
    about a composition that never happened.
    """
    mode: str
    crop_w: int
    crop_h: int
    crop_y: int
    src_dims: tuple[int, int]
    canvas: tuple[int, int]
    out_dims: tuple[int, int]
    rect_px: tuple[int, int, int, int]      # x, y, w, h in output pixels
    freedom: int
```

```python
"""Resolve a LayoutSpec into pixels (spec §7, design 2026-07-10).

The spec says what the episode wants; this says what ffmpeg must do. Keeping
the arithmetic here — and only here — is what lets check_episode and storyboard
read a sidecar instead of each re-deriving the crop and drifting apart.
"""
from dataclasses import dataclass

from scripts.lib import geometry
from scripts.lib.models import Delivery, LayoutSpec


@dataclass(frozen=True)
class ResolvedLayout:
    mode: str
    crop_aspect: tuple[int, int]
    crop_w: int
    crop_h: int
    freedom: int
    out_w: int
    out_h: int
    rect_px: tuple[int, int, int, int]      # x, y, w, h in output pixels
    background: str
    fast_path: bool


def _aspect(spec: LayoutSpec, canvas: tuple[int, int],
            src: tuple[int, int]) -> tuple[int, int]:
    if spec.crop_aspect == "canvas":
        return (canvas[0], canvas[1])
    if spec.crop_aspect == "source":
        return (src[0], src[1])
    return spec.crop_aspect


def resolve(spec: LayoutSpec, canvas: tuple[int, int], src: tuple[int, int],
            delivery: Delivery) -> ResolvedLayout:
    """Native size = the composite at which the inserted frame is NOT upscaled.

    canvas_w = crop_w / rect_w, canvas_h = canvas_w * canvas[1] / canvas[0] —
    both floats. Evenness is applied to each side independently, by Delivery, at
    the output: even(405) * 16/9 would drift 720 into 718.
    """
    aspect = _aspect(spec, canvas, src)
    crop_w, crop_h = geometry.crop_for(aspect, spec.crop_scale, src[0], src[1])
    free = geometry.freedom(crop_w, src[0])

    rx_f, ry_f, rw_f = spec.rect if spec.rect is not None else (0.0, 0.0, 1.0)
    if spec.mode == "fill":
        # the crop already carries the canvas aspect, so the canvas IS the crop.
        # Re-deriving canvas_h from crop_w drifts: a 21:9 crop of 4K is
        # 3840x1645, and 3840 * 9/21 evens to 1646, not the 1644 reframe
        # delivers today.
        canvas_w, canvas_h = float(crop_w), float(crop_h)
    else:
        canvas_w = crop_w / rw_f
        canvas_h = canvas_w * canvas[1] / canvas[0]
    out_w, out_h = delivery.dims(canvas_w, canvas_h)

    if spec.mode == "fill":
        # the fast path is a single scale={out_w}:{out_h} — an anisotropic squash
        # onto the full canvas, with no background to letterbox into. The crop
        # lands edge to edge, whatever its aspect. Deriving rh from the crop
        # aspect here would report a 718px card in a 720px canvas.
        rx, ry, rw, rh = 0, 0, out_w, out_h
    else:
        rw = geometry.even(rw_f * out_w)
        rh = geometry.even(rw * crop_h / crop_w)
        rx = int(round(rx_f * out_w))
        ry = (out_h - rh) // 2 if spec.rect is None else int(round(ry_f * out_h))
        if rx + rw > out_w or ry + rh > out_h:
            raise ValueError(
                f"layout rect {spec.rect} at crop aspect {aspect[0]}:{aspect[1]} derives a "
                f"{rw}x{rh}px card at ({rx}, {ry}), which overflows the {out_w}x{out_h} "
                "canvas — shrink rect w, move rect y up, or pick a taller crop aspect")

    return ResolvedLayout(mode=spec.mode, crop_aspect=aspect, crop_w=crop_w, crop_h=crop_h,
                          freedom=free, out_w=out_w, out_h=out_h, rect_px=(rx, ry, rw, rh),
                          background=spec.background, fast_path=(spec.mode == "fill"))
```

```python
def _filter_args(rl: ResolvedLayout, xexpr: str, cy: int,
                 gains: tuple[float, ...], fps: float) -> list[str]:
    """The ffmpeg filter arguments for one layout.

    fill takes the fast path: one -vf chain, byte-identical to what this script
    emitted before layouts existed. That is not an optimization — it is how the
    golden fixture is protected from a silent change of command.
    """
    mixer = color.mixer_arg(*gains)
    tail = f"{mixer},fps={fps:.6g},format=yuv420p"
    if rl.fast_path:
        return ["-vf", (f"crop={rl.crop_w}:{rl.crop_h}:x='{xexpr}':y={cy},"
                        f"scale={rl.out_w}:{rl.out_h},{tail}")]

    # but boxblur rejects a radius above half the chroma plane, and yuv420p
    # halves the plane again: the ceiling is min(out_w, out_h) // 4. A 3840x200
    # cover crashes at 64 and survives at 50.
    radius = max(2, min(rl.out_w // 60, min(rl.out_w, rl.out_h) // 4))
    return ["-filter_complex",
            (f"[0:v]split=2[a][b];"
             f"[a]scale={rl.out_w}:{rl.out_h}:force_original_aspect_ratio=increase,"
             f"crop={rl.out_w}:{rl.out_h},boxblur={radius}:2[bg];"
             f"[b]crop={rl.crop_w}:{rl.crop_h}:x='{xexpr}':y={cy},scale={rw}:{rh}[fg];"
```

```python
def reframe(spec: ReframeSpec, src: str, route_path: str, out: str, path_out: str) -> str:
    """Compose one episode from a tracked route (spec §6): crop/scale/color per `spec`.

    Writes `out` (the clip), `path_out` (the crop path) and `path_out`'s
    `.meta.json` sidecar — what was actually cut, for the checks to read back.
    """
    src_w, src_h, fps = _probe(src)   # NEVER assume dims/fps: real footage is 4K/60
    route = route_from_json(route_path)               # list[RoutePoint]
    if not route:
        raise ValueError(
            f"route {route_path} is empty — tracker found no hero frames; "
            "check route.meta.json (ambiguous? wrong seed pin?) before reframing")
    rl = layout_lib.resolve(spec.layout, spec.canvas, (src_w, src_h), spec.delivery)
    route_dicts = [p.to_dict() for p in route]        # compute_path/classify still take dicts
    motion = classify(route_dicts, src_w, src_h)
    path = compute_path(route_dicts, spec.composition, spec.grid, spec.canvas,
                        (src_w, src_h), motion, max_step=spec.max_speed / fps,
                        crop_w=rl.crop_w)
    CropPath(path).to_json(path_out)

    gains = color.gains_for_means(spec.color_means)
    times = [p.t for p in route]
    xexpr = _xexpr(path, times)
    mean_y = sum(p.y for p in route) / len(route)
    cy = g.crop_y(mean_y, rl.crop_h, src_h)
    cmd = ["ffmpeg", "-y", "-i", src,
           *_filter_args(rl, xexpr, cy, gains, fps),
           "-c:v", "libx264", "-crf", "18", "-preset", "medium", "-an", out]
    proc.run(cmd)

    PathMeta(mode=rl.mode, crop_w=rl.crop_w, crop_h=rl.crop_h, crop_y=cy,
             src_dims=(src_w, src_h), canvas=spec.canvas, out_dims=(rl.out_w, rl.out_h),
             rect_px=rl.rect_px, freedom=rl.freedom
             ).write(Path(path_out).with_suffix(".meta.json"))
    return out
```
