# Hero re-ID Embedding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 24-dim colour-histogram appearance descriptor with a 512-dim OSNet person-re-ID embedding (cosine), so the cast candidate list separates real people and the hero-pin machinery becomes usable.

**Architecture:** A new `lib/reid.py` is the only importer of `torchreid` (mirrors `lib/vidstab`'s isolation of libvidstab). `lib/appearance` keeps the pure crop helpers and swaps its distance to cosine; `lib/footage` bumps the on-disk descriptor length to 512. The two *producers* (intake, track) feed OSNet an **unmasked** bbox crop and carry 512-d vectors through the unchanged HeroPin / `hero.resolve` / cast.json plumbing. Cast surfacing becomes agglomerative clustering ranked by on-screen presence. reID is installed at setup baseline (warn-and-continue); its absence never blocks a run — the producer warns and skips cast, the explicit cast-pin consumer fails loud.

**Tech Stack:** Python 3.13, `torchreid` (OSNet `osnet_x1_0`, Market-1501 pretrained), torch (MPS/CPU), numpy, scipy (`scipy.cluster.hierarchy`, already present via librosa), PIL, ultralytics/ByteTrack (existing).

**Design:** [docs/specs/2026-08-04-hero-reid-design.md](../specs/2026-08-04-hero-reid-design.md).

## Global Constraints

- Run everything through the venv: `.venv/bin/python -m pytest ...`. Scripts are modules (`pythonpath = .`); never `python scripts/foo.py`.
- Fail-loud contract, imports-at-top. The ONE allowed exception is a heavy optional dep imported lazily inside the function that needs it (`torch`/`torchreid` in `lib/reid`, mirroring `track._iter_detections`'s lazy `ultralytics`). `numpy`/`scipy` are core deps — import them at top.
- `torchreid` stays OUT of `requirements.txt` — a failed torch/torchreid wheel must warn-and-continue at setup, not abort the venv (the demucs pattern, backlog #4).
- No new pip dependency other than `torchreid`. `scipy` is already installed via librosa.
- The descriptor is **512 floats, L2-normalized**; the metric is **cosine** (`appearance.descriptor_dist`, range [0, 2]); the crop fed to `reid.embed` is the **raw bbox crop in RGB, never masked** (a silhouette is out-of-distribution for OSNet — §10 landmine).
- Do NOT run installers (`pip install`, `bash setup.sh`) autonomously — not in the main session and not in any subagent. The real-OSNet test (Task 5) **skips** when torchreid is absent; it never installs it. Verification is read-only + pytest.
- Whole-object asserts where practical (compare the whole returned list/dict, per testing-guide).

```python
"""The only importer of torchreid — person re-ID embeddings (design 2026-08-04).

Isolated exactly like lib/vidstab isolates libvidstab: one module owns the heavy
optional dep, exposes available()/require()/ensure_model()/embed(), and every
consumer goes through it. torch/torchreid are imported LAZILY inside the functions
that need them (mirrors track._iter_detections' lazy ultralytics) so importing
this module — which the manifest gate never does, but the producers do — costs
nothing until an embedding is actually computed.
"""
import numpy as np

EMBED_DIM = 512                     # OSNet osnet_x1_0 feature width; footage.DESCRIPTOR_LEN mirrors it
_MODEL = "osnet_x1_0"
_REMEDY = ("run `bash setup.sh`, which installs torchreid (person re-ID) and "
           "fetches its OSNet weights")
_extractor = None                   # built once, reused; ensure_model() warms it before a pool


def available() -> bool:
    """True iff torchreid imports. The gate the cast paths consult; mirrors
    track.available()/flow.available()."""
    try:
        import torchreid  # noqa: F401  — lazy: the whole point is to not require it
        return True
    except ImportError:
        return False


def require() -> None:
    """Fail loud with a remedy unless torchreid is installed. Called at the entry
    of a path that CANNOT degrade — an explicit cast pin (mirrors vidstab.require)."""
    if not available():
        raise RuntimeError(f"torchreid is not installed — a cast/descriptor hero pin needs "
                           f"person re-ID to match an identity, and guessing from colour is "
                           f"exactly the failure this replaced. {_REMEDY}")


def _device() -> str:
    import torch
    return "mps" if torch.backends.mps.is_available() else "cpu"


def _get_extractor():
    global _extractor
    if _extractor is None:
        from torchreid.utils import FeatureExtractor
        _extractor = FeatureExtractor(model_name=_MODEL, device=_device())
    return _extractor


def ensure_model() -> None:
    """Materialize the OSNet weights ONCE before any concurrent embedding.

    Building the FeatureExtractor performs the one-time weight download; N pool
    workers starting cold would otherwise race the same download into the same
    path — the concurrent-writer landmine track.ensure_model already closes for
    YOLO (design §12/§10). Callers that fan out MUST call this first."""
    require()
    _get_extractor()


def embed(crops: list[np.ndarray]) -> list[list[float]]:
    """Batch RGB HxWx3 crops → L2-normalized 512-d vectors (one per crop).

    Empty in → empty out, short-circuited BEFORE require() so an all-scenery clip
    never needs the dep. FeatureExtractor accepts a list of ndarrays and applies
    its own resize/normalize; it treats an ndarray as RGB (design §10: we MUST
    hand it RGB — ultralytics orig_img is BGR and is converted upstream)."""
    if not crops:
        return []
    require()
    feats = _get_extractor()(list(crops))          # torch.Tensor (N, 512)
    arr = np.asarray(feats.detach().cpu().numpy(), dtype="float64")
    norms = np.linalg.norm(arr, axis=1, keepdims=True)
    norms[norms == 0] = 1.0
    return (arr / norms).tolist()
```

- [ ] **Step 3: Implement — `appearance.py`**

Replace the module's descriptor half. Keep `crop_bbox` and `_bbox_ltrb`. New top + functions:
```python
"""Appearance primitives (§6.1a layer 1 / design 2026-08-04).

The 512-d OSNet embedding itself is produced by lib/reid (the only torchreid
importer). This module stays numpy+PIL: it owns the pure cosine DISTANCE between
two embeddings and the crop helpers that feed reid.embed. footage.DESCRIPTOR_LEN
is the on-disk length; the metric here must agree with reid.embed's output
(L2-normalized), so descriptor_dist is a true cosine distance.
"""
import numpy as np
from PIL import Image

CAST_MATCH = 0.35     # max cosine distance for "this track IS that cast member" (design §5).
                      # Cosine range is [0, 2] (0 identical, 1 orthogonal, 2 opposite). A FIRST
                      # CUT calibratable on the real cache after the first re-scan — no footage
                      # exists to tune it (the repo's honest-threshold pattern). The real
                      # discriminator is min-distance + track.AMBIG_MARGIN; this only gates
                      # absence ("the pinned person is not in this episode at all").


def descriptor_dist(a: list[float], b: list[float]) -> float:
    """Cosine distance 1 - a·b between two L2-normalized embeddings. Range [0, 2]:
    0 identical direction, 1 orthogonal, 2 opposite. Operands MUST be L2-normalized
    (reid.embed's output, or a CastMember centroid) — that is this function's
    precondition and all it can check is that they agree in length: a distance
    between different-length vectors is meaningless (zip would silently truncate)."""
    if len(a) != len(b):
        raise ValueError(f"descriptor length mismatch: {len(a)} vs {len(b)} — a cosine "
                         f"distance between different-length vectors is meaningless. Both "
                         f"operands must be reid.embed outputs (512-d L2-normalized) or a "
                         f"footage.CastMember, which validates the same shape at the cast.json "
                         f"boundary.")
    return 1.0 - sum(x * y for x, y in zip(a, b))


def _bbox_ltrb(box: object) -> tuple[int, int, int, int]:
    """Clamp a box's centre-format xywh to integer (l, t, r, b), left/top >= 0."""
    x, y, w, h = (float(v) for v in box.xywh[0])
    l, t, r_, b_ = int(x - w / 2), int(y - h / 2), int(x + w / 2), int(y + h / 2)
    return max(0, l), max(0, t), r_, b_

def _centroid(descs: list[list[float]]) -> list[float]:
    import numpy as np
    m = np.asarray(descs, dtype="float64").mean(axis=0)
    n = float(np.linalg.norm(m)) or 1.0
    return (m / n).tolist()


def _medoid(members: list, centroid: list[float]):
    return min(members, key=lambda e: descriptor_dist(e.descriptor, centroid))


def surface_crops(entries: list, max_cast: int = MAX_CAST) -> list:
    """Cluster ALL tracks' embeddings into real identities (agglomerative, average
    linkage, cosine, cut at CLUSTER_COS), one CastEntry per cluster: descriptor =
    centroid (mean, re-L2-normed), representative crop = medoid, presence = sum
    over members. Ranked by presence (design §4.1); capped at max_cast with a
    logged drop — never a silent cap."""
    if not entries:
        return []
    import numpy as np
    if len(entries) == 1:
        labels = [1]
    else:
        from scipy.cluster.hierarchy import fcluster, linkage
        from scipy.spatial.distance import pdist
        Z = linkage(pdist(np.asarray([e.descriptor for e in entries], "float64"),
                          metric="cosine"), method="average")
        labels = fcluster(Z, t=CLUSTER_COS, criterion="distance").tolist()
    groups: dict[int, list] = {}
    for e, lab in zip(entries, labels):
        groups.setdefault(int(lab), []).append(e)
    picked = []
    for members in groups.values():
        cent = _centroid([m.descriptor for m in members])
        rep = _medoid(members, cent)
        picked.append(replace(rep, descriptor=cent,
                              presence=float(sum(m.presence for m in members))))
    picked.sort(key=lambda e: e.presence, reverse=True)
    if len(picked) > max_cast:
        print(f"cast surfacing: {len(picked)} identities clustered, keeping the top "
              f"{max_cast} by presence (dropped {len(picked) - max_cast})", file=sys.stderr)
        picked = picked[:max_cast]
    return picked
```
